# SoleCraftPH pitch promo: shot list

15 s · 1920×1080 (16:9) · 60 fps · 120 BPM (one beat = 0.5 s, one bar = 2 s) · English

Story, taken from the business model summary: problem (size sold out) → brand → solution features → CTA.
Every UI frame is a real screen captured from `solecraftfinal/design/apple-draft` (the app's design source)
or the real website screenshot. Nothing is invented: no ratings, no user counts.
